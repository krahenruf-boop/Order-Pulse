# 保留模块与共享依赖

当前服务包含余额监控、素材情报、客单价监控。三者保留各自配置、业务记录和调度；入口只监听本机，并保留 Host、Origin、CSRF 检查。

## 浏览器

- 余额监控使用原已确认空间及 Linkme 页面。
- 素材情报与客单价使用独立的「Order Pulse · 素材与客单价」空间。
- 两个空间分别核对名称、身份与页面，使用独立互斥锁。
- 采集继续使用已授权登录状态；不复制浏览器凭据。

## 共享依赖

- TMS 订单读取与导出保留付款时间、字符串订单 ID、分页、限流、数量复核和去重合同。
- 产品目录、SKU 别名供实采产品归组使用。
- 金额使用 Decimal，整单人民币金额不拆分；Wise 仅作参考换算。
- 飞书复用签名、返回码校验与有限重试组件，消息去重由保留模块各自管理。
- 历史快照保留原样；数据覆盖不完整时不覆盖上次完整结果。
