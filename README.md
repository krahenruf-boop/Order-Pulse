# Order Pulse

两套独立本机工作台，只监听 `127.0.0.1`：

| 工作台 | 地址 | 数据目录（当前用户 Application Support 下） |
|---|---|---|
| 余额＋API 监控 | http://127.0.0.1:8786 | Order Pulse Finance |
| 素材情报＋客单价 | http://127.0.0.1:8797 | Order Pulse Materials |

双击「启动 Order Pulse.command」启动两套后台。各自使用独立 LaunchAgent、数据库、日志、前端及调度。页面/接口不跨工作台提供。素材插件桥接 8876 只由素材后台启动，配对保持原样。

`tools/start.py finance` / `materials` 启动指定后台；`tools/stop.py finance` / `materials` 仅停止指定后台。不传参数管理两套后台。需使用项目 `.venv/bin/python`。旧 `local.order-pulse.service` 不再运行。

## 空间绑定与恢复

财务使用「Order Pulse · 余额 · API监控」，素材使用「Order Pulse · 素材与客单价」。数字 Space 编号重启后可能变化，只按保存的唯一名称、浏览器身份及任务标识恢复，不凭编号猜测。财务设置提供实际空间候选和「核验并绑定」，必须先确认 Linkme 登录和全部账户范围。重命名后使用该入口，业务配置和告警状态不重置。

财务空间保持 Agent 接管。素材空间默认接管；真实任务可立即接回，无任务时手动操作后连续键鼠空闲 5 分钟才接回。空闲计时不记录输入、不采集网页。任务结束返回所属工作台；Kalodata 由原插件后台标签采集，不激活来源页。需登录或验证码时等待本人完成；财务空间在此期间暂停其他自动夺回，完成后回到工作台手动刷新继续。

登录 macOS 后 LaunchAgent 自动启动；Ego Lite 需打开原浏览器身份和空间。网站登录、验证码或系统授权仍可能需要本人完成。马帮账号密码只在本机钥匙串，材料后台迁移不改变其逻辑空间范围。

## 余额与 API 通知

余额每小时采集；失败即时报警、持续故障每 6 小时提醒、成功恢复通知一次。历史账户配置、原机器人和发送去重状态保持。

API 监控默认每家每日北京时间 09:00 检测，初次启用先读一次并计入当天；页面和历史读取不采集。单家设置监控、推送、时间及阈值。剩余比例 **≤15%**（可单独修改）首次低额度报警，持续低额度不重复，额度实际恢复后通知一次。故障即时报警，每 6 小时提醒；**26 小时未成功读取**才判定日检过期。所有发送状态落库，超时不确定不重发，确定失败15分钟后重试。

- DeepSeek 使用可用余额和币种，首次正余额自动建立基准并记录日期；增加余额不重设基准，可手动修改/重设。
- ElevenLabs 使用当前账户唯一工作区当期总积分、已用、剩余及源站续订日期；不转换现金、不把按需付费当成无限额度。当前页面不显示具体重置时刻，原样注明。账户多工作区或身份改变时停止更新，需重新核验绑定。
- 不创建 API Key，不调用模型、语音生成或扣费接口。仅读取已登录网页的账户和额度信息。

## 数据迁移与清理

`tools/migrate_workstations.py` 仅在三套服务均停止且目标目录不存在时运行：先用 SQLite 一致性备份，再按模块复制表/凭据和必要配置，逐表计数及内容摘要核验。历史统计不重算，不回放旧通知。

验收后 `tools/archive_legacy.py` 保留一份校验过的压缩离线回滚库及原配置，删除旧运行数据库和重复备份。旧目录不参与运行。回滚须先停止两个新后台，再解压归档并核验 SHA256；不要让旧混合服务与新服务同时占用 8786 / 8876。

客单价每轮清理已用完的历史订单明细及不再覆盖滚动窗口的原始批次，仅保留最新详情、可重试任务、144 小时滚动计算必要批次和有效退款样本。历史统计、设置、通知记录保留；历史明细清理后页面明确说明。释放页面过多时自动压缩数据库，限制长期增长。无需清理浏览器登录数据。

电脑关机、休眠或后台停止期间不能即时通知；恢复运行后检查当前状态，不补发积压通知。主动暂停对应监控时不发故障报警。
