# Order Pulse

本机运营监控，服务仅监听 `127.0.0.1:8786`。

- 余额监控：账户余额、阈值和飞书通知。
- 素材情报：Kalodata 素材链接采集和导出。
- 客单价监控：按店铺产品观察 24/72 小时滚动客单价，增量同步、历史记录与告警。

双击「启动 Order Pulse.command」启动后台。数据位于当前用户 `~/Library/Application Support/Order Pulse/`。

## 浏览器空间

余额使用原专用空间中的 Linkme 标签；素材与客单价使用「Order Pulse · 素材与客单价」中的 Kalodata、马帮和妙手标签。两空间分别保存身份绑定。

保留各模块独立配置、历史、飞书凭据及本地订单缓存。前端刷新不触发采集。

余额空间持续保持接管。素材与客单价空间默认接管，真实任务可以立即接回；无任务时，手动操作后连续键鼠空闲 5 分钟才自动接回。空闲计时只读取系统空闲秒数，不记录输入，也不触发采集或刷新。客单价采集仍按配置周期运行。

重启后空间编号可能变化。程序会在原浏览器身份下按已保存的空间名称唯一识别并恢复绑定，无需重新填写编号；同名冲突或浏览器身份变化时停止恢复。未完成任务等待浏览器恢复期间每 20 秒重试，空闲时仍按原检测周期运行。后台通过登录启动项自动运行；需登录 macOS 并打开 Ego Lite 恢复原空间。网站登录失效、验证码与空间绑定是不同状态，仍需完成正常登录。
